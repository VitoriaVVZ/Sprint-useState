# Contador de Lotes Industriais

## Sobre o projeto

O projeto consiste em adaptar um componente contador em React para controlar a quantidade de caixas em um palete, respeitando os limites operacionais e evitando erros durante a contagem.

## Funcionalidades

- Controle de quantidade entre 0 e 50 caixas.
- Botões de incremento e decremento com validação de limites.
- Validação do passo de contagem entre 1 e 10.
- Indicadores visuais conforme o preenchimento do palete.
- Registro do último lote finalizado.
- Botão para zerar a contagem.

## Tecnologias utilizadas

- React
- JavaScript
- HTML
- CSS
- Vite

## Como executar o projeto

1. Clone este repositório.
2. Instale as dependências:

   ```bash
   npm install
   ```

3. Inicie o servidor de desenvolvimento:

   ```bash
   npm run dev
   ```

4. Acesse o endereço local exibido no terminal.
